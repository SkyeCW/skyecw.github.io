### 1、设备简述

**① 速度与存储**

*   **速度对比**：CPU > 内存 > 硬盘
*   **永久性存储**：硬盘、手机闪存
*   **易失性存储**：内存

**④ 核心数据流向**

*   **存储流向**：永久存储 → 易失存储（内存） → CPU
*   **外设流向**：输入设备 → CPU → 输出设备

### 1、CPU架构说明

CPU：中央处理器（Central Processing Unit)，计算机的核心部件，计算机的大脑



架构分类（详见[CPU 架构核心总结](#2、CPU 架构核心总结)）

x86架构（Windows操作系统只和它兼容）：intel、AMD、海光x86等（复杂指令集）功耗高、性能高 用于台式机、笔记本

arm架构：苹果A系列、华为的麒麟等（精简指令集）功耗低、性能相对较低 适应手机

mips：少见

RISC-V: 开源免费，潜力巨大、新出现的架构



### 2、CPU 架构核心总结

**安装软件的时候：记住安装对应架构软件**

- 注意区分amd和arm，架构的别名一定要搞清楚，不然到时候下错软件打不开，半天找不到问题
- 我犯了这个错，就是因为架构选了ARM的镜像，并且没有意识到自己的电脑无法运行基于这个镜像的虚拟机是架构问题



**1常见别名**

- **x86-64** = AMD64 = x86_64 = x64  
- **ARM64** = AArch64 = arm64



**2选择原则（记住）**

- **普通电脑（Intel/AMD）**：选 **x86-64 / amd64 / x64**
- **苹果 M 系列 Mac、树莓派、手机/平板**：选 **ARM64 / arm64 / aarch64**
- **嵌入式开发板**：按板载 CPU 确定架构，可能是 ARM、RISC-V、MIPS



3核心架构对比

| 架构      | 代表名称             | 位宽    | 核心特点                          | 主要场景                                          |
| --------- | -------------------- | ------- | --------------------------------- | ------------------------------------------------- |
| x86 家族  | x86 (IA-32)          | 32位    | CISC，老生态                      | 已淘汰，仅老旧设备                                |
|           | **x86-64**           | 64位    | 兼容32位x86，突破4GB限制          | **桌面、笔记本、服务器主流**                      |
| ARM 家族  | ARM (AArch32)        | 32位    | RISC，低功耗                      | 旧手机、低功耗嵌入式                              |
|           | **ARM64 (AArch64)**  | 64位    | ARM 64位扩展，不原生兼容旧32位ARM | **手机/平板主流、苹果M系列、树莓派、服务器、IoT** |
| RISC-V    | RISC-V               | 多种    | 开源、模块化、免授权费            | 嵌入式、IoT、定制芯片、学术、未来服务器/AI        |
| 其他/历史 | PowerPC、MIPS、SPARC | 32/64位 | 历史或专用RISC架构                | IBM服务器、网络设备、企业服务器等                 |

4关键区分

- **ISA 是指令集架构**：如 x86-64、ARM64
- **具体芯片是实现**：如 Intel Core、AMD Ryzen、Apple M、骁龙
- 同一 ISA 的不同实现，性能、功耗差异可能很大



5一句话总结

**桌面/服务器认准 x86-64；移动/树莓派/苹果M系列认准 ARM64；RISC-V 是开源新兴力量。**

### 3、CPU性能参数介绍

#### 3.1 主频与频率
*   **主频**：单位 GHz。数值越大，性能越强，但功耗和发热也越高（1 GHz = 10亿次/秒）。
    *   *实际处理速度估算*：核数 × 主频 × 0.8（单位：GHz）。
*   **睿频**：CPU最高超频上限。

#### 3.2 核心与线程
*   **核心数**：CPU内置物理处理器个数，越多性能越强。
*   **线程**：进程中的小任务。超线程即每个核心可同时处理多个线程。
*   **多任务**：并发执行（伪同时进行）；**单任务**：基本淘汰。

#### 3.3 三级缓存 (L1/L2/L3)
*   **定义**：CPU内临时存放计算数据的地方，性能越好缓存越大。
*   **规律**：
    *   速度：L1 > L2 > L3
    *   容量：L1 < L2 < L3
    *   查询顺序：L1 → L2 → L3 → 内存
*   **厂商差异**：Intel 为多核共享，AMD 为单核独享。

#### 3.4 热设计功耗 (TDP)
*   **定义**：芯片最大负荷时释放热量的指标（单位：W），**非实际运行功率**。
*   **笔记本常见功率**：

| 设备类型            | 典型功耗（持续/日常）           | 峰值功耗（高负载/瞬时）                                   |
| :------------------ | :------------------------------ | :-------------------------------------------------------- |
| **超轻薄本 (13寸)** | 15W – 30W                       | **50–60W**（高性能调校机型）                              |
| **主流办公本**      | 30W – 45W                       | **60–95W**（视性能释放策略）                              |
| **游戏本**          | 90W – 180W                      | **230W–255W（主流）；300–320W（2026旗舰）**               |
| **创作本/工作站**   | 120W – 200W                     | **200W左右（常规）；300W+（顶级型号）**                   |
| **MacBook系列**     | Air ~9W；14″ Pro ~27.5W（持续） | **Air ~70W；14″ Pro ~100W；16″ Pro 140W**（充电功率上限） |

*   *总结*：轻薄本主打低压续航；游戏/创作本高性能高功耗，需大功率电源。

#### 3.5 内存参数
*   **关键点**：需关注 CPU 支持的最大内存容量及频率。

#### 3.6 型号分类
*   **品牌前缀**：**R** 开头为 AMD 锐龙；**I** 开头为 Intel 酷睿。
*   **Intel 后缀**（以 i7 10700 为例）：
    *   **无后缀**：标准版。
    *   **K**：支持超频（多见于台式机）。
    *   **F**：无核显（较便宜，建议尽量买带核显的）。
    *   **H**：主频稍低，多用于笔记本。
    *   **U**：主频更低，主打轻薄长续航。
    *   **G**：带 Intel 锐炬核显（G7为高配核显）。
*   **AMD 后缀**：带 **G** 代表有核显，不带 G 则无。
*   *附参考*：[桌面CPU性能天梯图](https://www.mydrivers.com/zhuanti/tianti/cpu/)



### 4、如何查看电脑的 CPU 架构（Windows系统）

比较简单，可以去网上或问AI查自己型号对应架构。

前文提到过架构有 x86-64、ARM64 等，如果在 Windows 上不清楚自己的电脑是什么架构，可以用以下两种方法：

**方法一：使用 `msinfo32`（系统信息工具）**

1. 按下键盘上的 `Win + R` 键，打开“运行”窗口。
2. 输入 `msinfo32` 并回车。
3. 在弹出的窗口右侧，找到 **“系统类型”** 这一项：
   * 如果显示 `基于 x64 的电脑`，说明你的架构是 **x86-64**。
   * 如果显示 `基于 ARM 的电脑`，说明你的架构是 **ARM64**。
   
   示例：

![image-20261107221827282](%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A1%AC%E4%BB%B6%E5%9F%BA%E7%A1%80.assets/image-20261107221827282.png)

**方法二：使用 `systeminfo`（命令行系统信息）**
1. 打开“命令提示符”（CMD）或 Windows PowerShell。
2. 输入命令 `systeminfo` 并回车（需要等待几秒钟加载）。
3. 在输出的信息中，找到 **“系统类型”**（System Type），查看结果即可（同上）。

**💡 记笔记小贴士：**
* `msinfo32` 是 Windows 自带的**图形化**系统信息工具（好查）。
* `systeminfo` 是 Windows 自带的**命令行**系统信息工具（信息更全）。
* 查这个主要是为了**下软件、装系统、搞虚拟机**时对号入座（比如该下 `x64` 还是 `arm64` 的安装包）。





## 三、内存

### 1、内存说明

内存：CPU和硬盘之间交互数据时的**缓冲区**，提高CPU的利用效率，我们看到的**机带RAM**就是内存

**寻址大小**：一次性能处理的数据，比如一个电脑的CPU是64位，那CPU一次能处理的数据就时64位。32位地址总线能寻址 2^32^个独立地址，每个地址指向1字节。

**内存与CPU位**数：内存大小受限于CPU的位数，比如CPU的位数是32位，那么CPU支持的最大内存是2^32^B，即4GB，注意这里的1位等于1Byte。

单位换算：1Byte = 8 bit，1KB = 1024B

内存主频：内存的速度

DDR内存：

- DDR 133MHz、266MHz等频率
- DDR2 533MHz、800MHz等频率
- DDR3 1066MHz、1333、1600MHz等频率
- DDR4 2400MHz、2933、4300MHz等频率，目前是主要内存规格
- DDR5 6400MHz等频率



### 2、内存颗粒

内存颗粒：内存中的芯片，4G的内存如果有8个内存颗粒，那么每个内存颗粒的空间大小为4×1024÷8 = 512MB



### 3、内存双通道技术

双通道技术：一块数据可以分两部分写入两个内存中，速度更快，效率更高

四通道：两个颜色相同的两个通道，两个双通道

对比：两个8G比1个16G内存利用效率高，但稳定性差，其中一个有问题，电脑就容易崩





## 四、硬盘（disk)

**历史背景**：世界第一块硬盘是 IBM 于 1956 年生产的 **350RAMAC**，体积比冰箱还大，重达 1 吨，容量仅 5MB。

### 1、硬盘通用：接口、总线与协议

- **设备类型**：HDD、SSD。
- **物理接口/插槽**：SATA、M.2、SAS、U.2、IDE 等，决定“怎么插”。
- **总线**：SATA 总线、PCIe 总线，决定“走哪条数据通道”。
- **协议**：AHCI（对应 SATA）、NVMe（对应 PCIe）、SCSI（对应 SAS），决定“用什么语言通信”。

| 层级              | 内容                     | 说明                                          |
| :---------------- | :----------------------- | :-------------------------------------------- |
| **设备类型**      | HDD、SSD                 | SSD 是设备类型，不等于 NVMe。                 |
| **物理接口/插槽** | SATA、M.2、SAS、U.2、IDE | M.2 是物理接口，可走 SATA，也可走 NVMe/PCIe。 |
| **总线**          | SATA 总线、PCIe 总线     | 决定数据通道。                                |
| **协议**          | AHCI、NVMe、SCSI         | 决定通信语言。                                |

- **SATA**：Serial ATA，串行 ATA，是接口/总线标准，对应 **AHCI 协议**；SATA 3.0 理论接口带宽 6 Gbps，有效数据带宽约 600 MB/s。
- **NVMe**：Non-Volatile Memory Express，基于 **PCIe** 总线设计的**协议**，不是接口，通常搭配 M.2 或 U.2 接口；主要用于 NVMe SSD，HDD 几乎不用。参考：[(12 条消息) 一篇文章讲清什么是NVMe - 知乎](https://zhuanlan.zhihu.com/p/71932170)
- **一句话记忆**：**SSD 是设备，NVMe 是协议，M.2 是接口；三者常见搭配，但不等同。HDD 常见 SATA/SAS，几乎不用 NVMe。**



### 2、机械硬盘（HDD）

机械硬盘（Hard Disk Drive, 简称HDD）

- **核心结构**：马达、磁盘（磁性物质存储）、磁头臂、磁头（负责读写）。
- **内部环境**：密封填充氮气或氦气。氦气密度低，阻力小，能让磁头更贴近盘面以增加容量。但氦气存在泄漏风险（质保通常 5 年），一旦漏光触发写保护，需立即备份。
- **关键参数**：
  - **转速**（RPM）：每分钟转速。越快性能越好，但噪音越大（台式机常见 7200，笔记本常见 5400）。
  - **尺寸**：台式机 3.5 寸，笔记本 2.5 寸。
- **接口**：HDD 常见接口为 SATA/SAS

磁盘是磁性物质，通过磁性物质来进行数据的存储，通过写磁头写入数据，通过读磁头，读写数据

磁盘是密封的，里面一般都是填充氮气或氦气等等，氦气密度低，磁盘旋转阻力小，磁头可以悬停在盘面更近的距离，于是就可以安更多的盘面和磁头，实现更大的磁盘容量，降低存储设备。但是泄露不可避免，一般氦气盘的质保是5年，只要五年氦气没漏光就行 。氦气漏到一定程度，磁盘会进入写保护状态，发出警告。此时，应当赶紧备份磁盘数据。



### 3、固态硬盘（SSD）

- **全称**：Solid State Disk或Solid State Drive。
- **原理**：电子存储（将电子囚禁在绝缘层中），材质类似手机闪存。
- **接口与协议**：SSD 常见 SATA、M.2（NVMe/PCIe）、U.2 等，具体见[硬盘通用：接口、总线与协议](#1、硬盘通用：接口、总线与协议)
- **特点**：比 HDD 更稳定耐用、更轻薄，但价格更贵。
- **💡 个人备忘**：SSD 价格波动大（如 2026 年初曾大涨）。买盘时关注 **TBW**（总写入量）指标，如 2TB 盘 TBW=600TB，理论上可正常使用十多年。





## 五、显卡（GPU）

显卡的好坏直接决定了画面的流畅度与图形处理能力（尤其是大型游戏）。可通过 [显卡天梯图](https://pic4.zhimg.com/v2-ac8cb944ed46323db0f5ef48b56add03_1440w.webp?consumer=ZHI_MENG) 参考性能排行。

### 1、显卡分类说明

*   **独立显卡（独显）**：拥有独立的显存和芯片，性能强劲。
    *   *笔记本特例*：通常带 **M** 后缀（如 GTX 980M）。因散热受限，性能会低于台式机同级别显卡（如 GTX 980M 性能约等于台式机 GTX 970）。
*   **集成显卡（核显）**：无独立物理显存，使用**共享GPU内存**（Shared GPU Memory）。这是从系统内存（RAM）中动态划分的一部分虚拟显存，供GPU临时调用。
*   **AI 视角**：**跑本地 AI 必须用独显**。核显只能跑极轻量级模型（如基础 TTS），跑大语言模型或生成视频基本不可用。

### 2、核心性能参数

*   **显存（帧缓存）**：存储显卡处理过或即将提取的渲染数据。**容量决定“能不能跑”。**
    *   **帧率（FPS）与流畅度**：肉眼流畅需至少24帧，实际视频/游戏通常需30帧以上。
    *   **匹配原则**：显卡输出帧数需与显示器刷新率匹配（如显卡支持90FPS，显示器仅60FPS，会浪费30帧）。
    *   **分辨率与显存**：分辨率越高（如1080P -> 2K），单张图像占用空间越大，所需显存容量也越大。**买显卡必须关注其支持的最大分辨率**。
    *   *AI 实战*：本地大模型/绘图模型必须完整装进显存。借助量化技术（压缩精度），**8G显存**可跑7B级别语言模型或基础绘图；**16G显存**是个人甜点（跑14B模型、量化版Flux绘图、轻量视频）；**24G显存**可跑30B模型、全精度Flux或主流视频生成。
*   **显存频率**：单位 MHz，频率越高，速度越快。
*   **显存位宽**：显存一次性传输的数据量。类比公路车道，位宽越大性能越高（常见 64 / 128 / 256 / 512 位等）。
*   **显存带宽**：数据吞吐量指标。**决定 AI 跑得快不快。**
    *   **计算公式**：`显存频率 × 显存位宽 / 8`。
    *   *示例*：频率 500MHz × 位宽 128位 / 8 = 8 GB/s。
    *   *AI 实战*：AI生成文字（Token）本质是“访存密集”任务，每写一个字都要读取一遍完整模型。带宽越宽，生成速度（Token/s）越快。注意：部分入门卡显存大（如16GB）但位宽窄（128位），大模型能装下但生成速度慢。
*   **CUDA核心 / Tensor Core**：显卡内部的处理器。
    *   **CUDA核心**：数量越多，通用图形处理和并行计算能力越强。
    *   **Tensor Core（张量核心）**：**AI 专用硬件**。专门加速矩阵运算，是跑大模型的核心算力来源，支持 FP16/INT8/FP4 等低精度计算。它能让 AI 运算效率成倍提升。

### 3、核显与独显性能对比

*   **带宽差距**：共享内存的带宽通常不足专用显存的 **1/10**，且延迟更高。
*   **性能上限**：即便核显共享显存可达16GB，其实际游戏性能也仅约等于入门独显（如 GTX 1050），且高度依赖**双通道高频内存**，不适合高负载场景。
*   **AI 视角**：由于核显带宽极低（存在“等数据”问题），且系统内存与显存调度存在瓶颈，跑大模型的输出速度会极其缓慢（卡顿感强），仅适合尝鲜体验。

**💡 AI 个人部署极简参考（按显存档位）**：
*   **8GB**：轻度文字对话（7B量化）、基础画图（SD 1.5）。
*   **12GB - 16GB**：进阶语言模型（14B量化）、高清绘图（SDXL、FP8量化Flux）、基础声音克隆、跑轻量视频生成。
*   **24GB（及以上）**：生产力级体验（30B+大模型、全精度Flux绘图、22GB级视频生成、高保真音频）。



## 六、主板

主板图解示例：

![主板图示](%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%A1%AC%E4%BB%B6%E5%9F%BA%E7%A1%80.assets/%E4%B8%BB%E6%9D%BF%E5%9B%BE%E7%A4%BA.png)

**核心原则**：主板的 CPU 插槽必须与 CPU 接口一致。

#### 1、芯片组分类（以 Intel 为例）
*   **高端**：Z系列（如 Z690），支持超频，扩展性强。
*   **中端**：B系列（如 B660），**性价比首选**，适合大多数用户。
*   **低端**：H系列（如 H610），基础够用，价格最低。

#### 2、品牌厂商
无论是 Intel 还是 AMD 平台，主板品牌梯队和选购逻辑基本相同：

- **一线品牌（御三家）**：**华硕、技嘉、微星**。这三家占据市场主流，BIOS 研发实力强，稳定性极高。
- **二线/三线品牌**：七彩虹、铭瑄、盈通、昂达等。主打低价走量，性价比高，但 BIOS 功能和超频潜力相对较弱。

**选购建议**：

- **追求极致稳定与顶级售后**：选 **华硕**（需接受一定的品牌溢价）。
- **追求一线品质+高性价比**：选 **技嘉**（同价位用料通常较扎实）或 **微星**（产品线均衡，BIOS 对新手友好）。
- **预算吃紧，追求极致低价**：选 **七彩虹、铭瑄** 等二线品牌。

#### 3、关键选购参数
*   **CPU 插槽**：随 CPU 针脚代数变化（如 Intel 的 LGA1700 专用于 12 代处理器，通常两代换一次插槽）。
*   **内存支持**：
    *   **类型**：必须匹配（DDR4 或 DDR5）。
    *   **容量上限**：由 CPU 支持和主板的内存插槽数量共同决定。
*   **显卡支持**：部分主板支持双显卡“交火”（CrossFire）技术，效率高于单卡，适合大型游戏玩家。**注意**：并非所有主板都支持，需视主板规格而定。



## 七、其他设备

### 1、接口

- **视频接口（信号传输）**：
  *   **VGA**：模拟信号，已基本被淘汰。
  *   **DVI / HDMI / DP**：均为数字信号。
      *   **HDMI**：普及度极高（电视、游戏机标配）。HDMI 2.1 带宽达 48Gbps，支持 8K@60Hz 或 4K@120Hz。
      *   **DP (DisplayPort)**：适合高刷新率、多显示器配置（支持菊花链）。最新 DP 2.0 带宽达 80Gbps，支持 8K@60Hz 或 4K@144Hz。
- **数据/外设接口**：
  *   **USB-A**：传统长方形接口，用于接 U盘、键鼠等，传输速度通常比 Type-C 慢。
  *   **USB-C**：主流扁平圆角接口（同多数手机充电口），支持正反插。
  *   **SD 卡槽**：长条形，用于读取存储卡。
- **其他接口**：
  *   **3.5mm 音频接口**：圆形，连接有线耳机、麦克风。
  *   **电源接口**：形状不一，视设备而定。

### 2、电源选购原则

主要是针对自己组装的

*   **核心公式**：**CPU功耗 + 显卡功耗 < 电源瓦数** （需预留一定余量）。
*   **功耗评估**：耗电大头是 CPU 和显卡，其他部件功耗较低。可通过“鲁大师”等工具测算。



### 3、其他部件（略过）

主机箱、键盘、鼠标、显示器、独立声卡、网卡等。



## 八、计算机分类

### 1、按照性能和用途分

**性能**分：

- 1、巨型机：也叫超算，即超级计算机
- 2、大型机

- 3、中型机：供中小企事业单位使用
- 4、微型计算机：又称个人电脑，体积小，通用性强，价格低廉、对使用环境要求不高、软件丰富等

- 补充：**传统分类中有小型机，介于大/中型机与微机之间，后其定位逐渐被PC、工作站和服务器取代**

**功能**分：

- **个人计算机（PC/微型计算机）**：即**普通办公本、家用台式机、游戏本**等。体积小、通用性强，主要用于日常办公、娱乐、上网等常规任务。
- **工作站**：个人计算机中的**“特种兵”**。同样是办公，但它面向的是工程CAD设计、3D动画渲染、科学计算等**专业领域**，配备专业级显卡和高可靠性硬件，性能远超普通办公本。
- **服务器**：为网络中的其他计算机（客户端）提供计算、数据存储、网络管理等服务的**专用**计算机。（注：轻量场景下也可由高性能微机充当，但企业级通常为专用硬件）。
- **信息设备（移动终端）**：如智能手机、平板电脑、智能穿戴设备等，便携性强，主要执行通信、信息浏览等特定任务。
- **嵌入式计算机**：嵌入在其他机器或设备内部，专为满足特定功能需求（如控制、监测）而设计的专用计算设备（如智能家电、汽车ECU、工业机器人控制器）。

## 九、设备查看

以下为常用的电脑硬件信息查看方式：

### 1、系统自带工具

- **基础信息（直观）**：右键点击**“此电脑”** -> 选择**“属性”**。可查看 CPU 型号、内存容量、系统版本等。
- **设备管理器（全面）**：按下 **`Win + X`** 快捷键，选择**“设备管理器”**。可查看所有硬件设备的详细列表及驱动状态。
- **任务管理器（实时）**：使用快捷键 **`Ctrl + Shift + Esc`**，或右键点击任务栏空白处打开。可查看 CPU、内存、磁盘和 GPU 的实时占用率与具体型号。

### 2、第三方工具

有些第三方可能比系统自带的更好用

- **鲁大师等软件**：可一键查看完整配置清单、硬件跑分及温度监控。
- **图吧工具箱**：内置各种检测工具，更全能
